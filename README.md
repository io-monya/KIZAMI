# 刻 KIZAMI — lyric timing marker

*crafted by IO/monya*

English: README.en.md

公開版：https://dev.iomonya.com/kizami/ （ブラウザで開くだけで使えます）
ライセンス：MIT（LICENSE）

曲を聴きながらキーを押してマーカーを打ち、そこに歌詞を入れて、
歌詞のタイミング（TSV・SRT・VTT・LRC）を書き出すためのツールです。

## 開き方
`index.html` をブラウザで開くだけで使えます。Chrome と Safari で動作を確かめています。
パソコンのキーボードで使う道具です。スマホやタブレットで開くと、そのことを知らせる案内が出ます（閉じれば中を見られます）。
曲も歌詞もブラウザの中で読み込むだけで、外部には送信しません。

## 対応しているファイル
| 種類 | 形式 |
|---|---|
| 曲 | mp3・wav・m4a・aac・flac・ogg・opus |
| 動画（音声だけを使います） | mp4・m4v・mov・webm |
| 歌詞 | txt・md・docx・rtf・html |
| 作業ファイル | json |
| タイミング | tsv・srt・vtt・lrc |

- ボタンの選択画面にも、画面へのドロップにも、同じ形式が使えます。それ以外のファイルは読み込まずにお知らせします
- 動画は中の音声だけを取り出し、映像は使いません。ブラウザが読めない音声形式の動画は「音声として読めませんでした」と表示されます
- 読み込める大きさは、音声・動画が 300 MB・40 分まで、Word（.docx）が 30 MB まで、そのほかのテキスト系のファイルが 8 MB までです

### 歌詞のファイルについて
- 歌詞は文字だけを読み込みます。太字・色・見出し・リンク・表などの書式は読み込みません。表は 1 行を 1 行の歌詞として読み込みます
- 文字コードは UTF-8 と Shift_JIS のどちらでも読み込めます
- Google ドキュメントは「ファイル」→「ダウンロード」から Word（.docx）か Markdown（.md）で保存すると読み込めます
- PDF は読み込めません。PDF を開いて文字をコピーし、LYRICS の鉛筆のボタンを押して貼り付けてください
- 古い Word 形式（.doc）と Pages の書類は読み込めません。Word（.docx）として保存するか書き出してから読み込んでください
- ふりがな（ルビ）は読み込みません。Word の変更履歴で削除された文字も読み込みません

## 基本の流れ
1. 曲（mp3 など。動画も可）と歌詞（.txt・.docx など）を読み込みます。ファイルを画面へドロップしてもかまいません
2. 曲を再生しながら、歌い出しに合わせて `M` を押してマーカーを打ちます（打つキーは変更できます）
3. 歌詞を選び、右のマーカー一覧か波形上のマーカーへドラッグします
   - マーカーを選んだ状態で `Enter` を押しても入ります。入れると次のマーカーへ進み、カーソルは次の歌詞の先頭へ移るので、`⇧End` や `⌥⇧→` → `Enter` の繰り返しで進められます
   - Intro などの見出しは、選ばずに飛ばしてかまいません
4. 全体が遅れているときは「打鍵の遅れ補正」（Offset、−1000〜＋300 ms）でまとめて調整します。細かいずれは、波形上でマーカーをドラッグするか `,` `.` で直します
5. 再生して、画面上部の大きな文字で確認します
6. Export から形式を選んで書き出します

注意
- 日本語入力のままだとキーが効きません。英数入力に切り替えてから使ってください
- 読み込んだ曲は、ブラウザの中で一度 wav に変換してから再生します（mp3 でシークしたときに時刻がずれるのを防ぐため）。元のファイルは変更しません
- Bluetooth イヤホンで聴きながら打つと、マーカーが遅れます（0.5 秒前後。機器や接続状態によって変わります）。有線イヤホンかスピーカーで打つことをおすすめします

## 画面
- 歌詞とマーカーのあいだの仕切りをドラッグすると、それぞれの広さを変えられます。ダブルクリックで半分ずつに戻ります。画面の幅が狭いときは、歌詞が上・マーカーが下に積まれ、仕切りで上下の高さを変えられます
- 画面の幅が狭いとき（640px より狭いとき）は、上の段の SPEED・KEY・OFFSET の文字を隠して、段の数を減らします。それぞれの意味は、マウスを乗せると出ます
- 右上の ？ で操作説明が、？ から出る吹き出しの形で開きます。キーの一覧もここにあります。初めて開いたときは自動で開きます。説明の外をクリックするか `Esc` で閉じます
- 上部のボタンは記号で表示しています（♪ 曲／横線 歌詞／フォルダ 開く／▶ 再生（再生中は ❚❚）／下向き矢印 保存）。マウスを乗せると説明が出ます
- マーカーの一覧の各行には、▶ 少し前から再生／消しゴム「ここで文字を消す」マーカーに切り替え（その行では T で歌詞のマーカーに戻す）／三つに分かれた箱 一文字ずつ分ける／ごみ箱 削除、のボタンが並びます
- マーカーの個数は、MARKERS の文字にマウスを乗せると出ます。2 個以上選んでいるときは、見出しの横に選んでいる数が出ます
- 右上の ◐ で、配色を白 → 黒 → ネオン の順に切り替えます。初めて開いたときは白です。黒と白はマーカーを明るさの違いだけで見分けられるようにし、再生位置の線だけに色を付けています（黒は黄色、白は赤）
- 波形の下の段も記号で表示しています（左から：拡大・表示する時間のバー・縮小／再生位置を追う／拍の目盛りの表示・メトロノーム・吸着・設定／A・B・くり返し・打ち直し・区間を消す（マーカーは消えません）／波形の操作の説明）。バーは左で拡大、右端で曲の全体を表示し、色の付いた部分がおおよその表示範囲を表します。オンになっているボタンは枠に色が付きます
- 画面の幅を狭めると、ボタンは組ごとに折り返します
- LYRICS と MARKERS の見出しの右にある −／＋ とつまみで、それぞれの文字の大きさを 50〜200% で変えられます。つまみは真ん中が 100% で、ドラッグすると 5% 刻みで動きます。数字をクリックすると 100% に戻ります
- ボタンやつまみにマウスを乗せると、説明が出ます。LYRICS の見出しの文字に乗せると、歌詞の入れ方が出ます
- 右上の EN／JA で、表示を日本語と英語で切り替えます。初めて開いたときはブラウザの言語に合わせます（日本語以外なら英語）
- 配色・文字の大きさ・言語は、次に開いたときも引き継がれます

## マーカーの文字を直接入力する
- マーカー一覧の歌詞欄をクリックすると、文字を直接入力できます（一文字ずつのタイミングや、歌詞カードと違う表記を入れたいときなど）
- `Enter` で確定、`Esc` で取り消し、空にして確定すると歌詞の入っていないマーカーに戻ります
- 直接入力した行には ✎ が付きます

## 歌詞の編集
- LYRICS の鉛筆のボタンで、読み込んだ歌詞をその場で編集できます（改行・ひらがなへの書き換え・言い換えなど）。元のファイルは変更しません
- ✓（`⌘Enter`）で確定すると、置いてあったマーカーは編集後の歌詞へ引き継がれ、マーカーの文字も新しい表記になります。✕（`Esc`）で編集をやめます。編集中は、見出しの横に「編集中」と表示されます
- 削除した部分に置いてあったマーカーは、直接入力した文字（✎）として残ります。`⌘Z` で編集前に戻せます
- 編集した歌詞は自動保存と作業ファイルに含まれます。歌詞を読み込まずに鉛筆のボタンから入力したり、貼り付けたりすることもできます

## 拍の目盛り
- 波形の下にある「拍の目盛り」の **表示** と **吸着** は、それぞれ別にオン／オフできます
- 吸着が効くのは、オンにしたあとに打ったマーカー（`M`・`X`・波形のダブルクリック）だけです。すでにあるマーカーは動きません。目盛りに合わせたいマーカーは、選んで `G` を押します
- 寄せる範囲は「最も細かい刻みの何 % 以内なら寄せるか」で指定します（5〜50%、初期値 25%）。50% にすると、常に一番近い線へ寄ります
- 「設定」で、区間ごとに一拍目の位置・BPM（入力は 0.01 刻み、二点で合わせた場合は 0.001 まで）・拍子・細かさを決めます
- テンポや拍子が変わる位置では「＋ 再生位置から新しい区間」で区間を追加します。最初の区間は、一拍目より前（弱起）にも線を表示します
- 一拍目の位置は「再生位置を一拍目に」で設定するか、波形の下端で区間の線をドラッグして動かします。再生中に設定した場合は打鍵の遅れ補正を加えます
- 「二点で合わせる」：一拍目と、指定した小節数だけ後の一拍目の 2 か所から BPM を計算します
- 「タップで測る」：曲に合わせて押すと、おおよその BPM を測れます（設定を開いているときは `T` でも押せます）
- 目盛りの設定は作業ファイルにも保存されます
- メトロノーム（目盛りの表示ボタンの右）：再生中、目盛りの拍に合わせて鳴らします。オン／オフはボタンで、音量・音色（クリック・ウッドブロック・電子音）・「小節の一拍目を高い音に」・「細かい刻みも小さく鳴らす」は目盛りの設定で選べます。再生の速さに合わせて遅く・速くなります。メトロノームの設定はブラウザに保存され、作業ファイルには入りません

## 遅れの測定
- 上部の「Offset」の文字か、時計のボタンで測定の画面が開きます
- 「ピッ、ピッ」という合図の音に合わせて `M`（マーカーを打つキー）か `Space` を押します。キーの代わりに、測定の囲みの中をクリックしても打てます。最初の 4 回は聴くだけです
- マーカーを打つときと同じ経路（曲を再生する `<audio>`）で測るため、イヤホンの遅れと指の遅れをまとめて測れます
- 測定が終わると「補正を ○ ms にしますか？」と確認します。「反映する」を押すまで補正値は変わりません

## A–B と打ち直し
- `A`・`B` キーで、再生位置を A・B に設定します（波形を `⌥` を押しながらドラッグしても設定できます）。`L` で A–B をくり返し再生します
- 置いた A・B は、波形の上でドラッグして微調整できます。線の外側の小さな札（A は左、B は右）をつかむと、近くにマーカーがあっても A・B のほうが動きます。A と B は追い越しません
- `R`（打ち直し）：A の 1.5 秒前から再生し、A–B にあるマーカーを、打った順に新しい時刻へ移します。歌詞はマーカーに入ったままです
  - 打った回数のほうが多ければ新しいマーカーを追加し、少なければ残ったマーカーは元の位置のまま選択されます
  - B を過ぎると停止します。`Esc` か `Space` でも停止します。`⌘Z` で打ち直す前に戻せます

## 一文字ずつ分ける
- 一覧の三つに分かれた箱のボタン（またはマーカーを選んで `S`）で、そのマーカーの歌詞を細かく分けます
  - 「字」：一文字ずつ。小さい字（ゃ・っ など）・ー・記号は前の文字とまとめ、英単語は単語ごとにまとめます。行頭の「……」や「「」は次の文字とまとめます
  - 「語」：空白で区切った言葉ずつ
- 元のマーカーは最初の一つになり、残りは次のマーカーまでの間に等間隔で仮に並びます。続けて少し前から曲が再生されるので、曲に合わせてキーを押すと、押した順に新しい時刻へ移ります（打ち直しと同じ動作です）
- 途中で止めた場合、まだ打っていない分は仮の位置のまま選択されます。`⌘Z` で分ける前に戻せます

## マーカーをまとめて操作する
- 波形の空いた所をドラッグすると、範囲にかかったマーカーを選択できます（`⇧` で追加）。一覧では `⇧`＋クリックで範囲、`⌘`＋クリックで一つずつ選択できます。`⌘A` ですべて選択します
- 選んだマーカーは、ドラッグでまとめて動かせます。`,` `.` でまとめてずらし、`Delete` でまとめて削除し、`G` でまとめて目盛りに寄せます。`Esc` で選択を解除します

## 書き出しと読み込み
- Export から形式を選びます：TSV（KIZAMI・灯字（TOMOJI）用）／SRT（Premiere・YouTube などの字幕）／VTT（Web の字幕）／LRC（歌詞の同期表示）
- SRT・VTT の終了時刻は次のマーカーの時刻です。最後の行は開始から 4 秒後になります
- フォルダのボタン（または画面へのドロップ）で、作業ファイル（json）のほか、tsv・srt・vtt・lrc も開けます。歌詞が読み込まれていれば対応する文字を探して結びつけ、読み込まれていなければファイルの文字から歌詞を作ります

## キー
| キー | 動作 |
|---|---|
| Space | 再生／停止 |
| M（変更可） | 今の位置にマーカーを打つ |
| X | 「ここで文字を消す」マーカーを打つ |
| Enter | 選んだ歌詞を、選択中のマーカーへ入れる |
| [ ] | 前／次のマーカーを選ぶ |
| , . | 選んだマーカーを 10 ms 動かす（⇧で 50 ms） |
| P | 選んだマーカーの 1.5 秒前から再生 |
| G | 選んだマーカーを、拍の目盛りの一番近い線へ寄せる |
| S | 選んだマーカーを一文字ずつ分けて打つ |
| Delete | 選んだマーカーを削除（歌詞欄の外で） |
| A / B | 再生位置を A・B に設定 |
| L | A–B をくり返し再生 |
| R | A–B を打ち直す |
| ⌘A | マーカーをすべて選択 |
| Esc | 選択を解除・画面を閉じる・打ち直しを止める |
| ← → | 3 秒戻る／進む（歌詞欄の外で） |
| ⌘Z / ⇧⌘Z | 元に戻す／やり直す |
| ⌘S | 作業ファイル（.json）を保存 |

波形：クリックで再生位置を移動、マーカーはドラッグで左右に移動、空いた所をダブルクリックでマーカーを追加、⌘＋ホイールで拡大・縮小。

## 保存
- 最後に自動保存した日時は、画面のいちばん下の右端に出ます
- 作業はブラウザに自動保存され、同じ曲と歌詞（ファイル名で判別）を読み込むと、続きから再開できます
  - 保存先はブラウザ内の保存領域（localStorage）です。Chrome の場合は `~/Library/Application Support/Google/Chrome/Default/Local Storage/leveldb/` にありますが、通常のファイルとしては読めません
  - 同じ Mac・同じブラウザ・同じプロフィールでのみ参照できます。閲覧履歴データを削除すると消えます。保存できる量は数 MB までです
- 確実な控えは「作業を保存」（`⌘S`）で書き出す `<曲名>_kizami.json` です（ブラウザのダウンロード先に保存されます）。別の日・別の Mac・別のブラウザでも、フォルダのボタンから開いて再開できます。区切りのよいところで保存してください

## 安全面（配布するときのために）
- 曲・歌詞・作業内容は、使う人のブラウザの中だけで扱います。外部への通信は一切行わず、ページ自体にも「外部と通信しない」制限（Content-Security-Policy）を付けています
- 作業ファイル（json）や tsv・srt・vtt・lrc を開くときは、中身の型と範囲をすべて確認してから使います。細工されたファイルを開いても、ページの中で勝手な処理は動きません
- 読み込みの上限：テキスト系ファイル 8 MB（Word は 30 MB）、音声 300 MB・40 分、歌詞 100,000 文字、マーカー 20,000 件（1 件 5,000 文字）。超えた分は読み込まずに通知します
- 自動保存は、前回の作業を復元するか確認するまで上書きしません。復元を断った場合、前回分は別名で残ります
- 2026-11-07 に外部の監査（Astra）を受け、指摘事項に対応済みです（AUDIT_RESPONSE_2026-11-07.md）
- ブラウザへの自動保存は、同じドメインの他のページからも読める仕組みです。KIZAMI を公開するときは、他の人のスクリプトを載せるページとはドメインを分けることをおすすめします

## TSV の中身（`<曲名>_timing.tsv`）
タブ区切り、UTF-8。

```
start_sec	end_sec	text
20.350	22.420	I was teaching him, reaching in, keeping it crisp,
```

- 打鍵の遅れ補正は反映済みです
- end_sec は次のマーカー（歌詞のマーカーまたは文字を消すマーカー）の時刻です。最後の行は空欄になります
- 歌詞が入っていないマーカーは書き出しません
- 一つのマーカーに複数行ある場合、改行は ` / ` に置き換えます
